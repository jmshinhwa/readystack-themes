# 電帳法 索引簿リンター (電子取引データ検索要件)

![電帳法 索引簿リンター (電子取引データ検索要件)](https://getreadystack.com/img/promo/sku128975_result_card.jpg)

電子取引データの**索引簿 (CSV)** を、電子帳簿保存法の**検索要件3項目**とファイル名規則で**行ごとに**検査します。日本の個人事業主・小規模法人の経理担当者向け。エディタの中だけで動き、データはどこにも送信されません。

ハブ: https://getreadystack.com/ja/tools/denchoho-sakuinbo-lint-jp

## これが見つけるもの

電子取引 (メール添付のPDF請求書・Web明細のダウンロード・EDI) のデータは、電子のまま保存し、**取引年月日・取引金額・取引先**の3項目で検索できる状態にしておく必要があります。基準期間の売上高が **5,000万円**以下などの要件を満たし、ダウンロードの求めに応じられる場合は検索要件そのものが不要になりますが、その判定をしたうえで索引簿を作っている事業者は、索引簿が実際に「検索できる形」かどうかで詰まります。

詰まる場所はいつも同じです。和暦、全角数字、`同上`、`請求書 (2).pdf`、同じファイル名の2重割り当て。人の目には読めますが、日付や金額の範囲で引くと当たりません。

## ルール13本

| id | 見るところ |
|---|---|
| `header_missing` | 取引年月日・取引金額・取引先の見出し列があるか |
| `date_format` | 和暦・曜日つき・全角 (`令和8年4月5日`) |
| `date_invalid` | 存在しない日付 (`2026-13-02`)・未来日 |
| `amount_missing` | 取引金額の空欄 |
| `amount_format` | 全角・注記混じりで範囲検索できない金額 |
| `amount_taxnote` | `税抜` `税別` 表記 (索引簿の取引金額は税込総額) |
| `party_missing` | 取引先が空欄・`同上`・`不明` |
| `file_missing` | 保存ファイル名が空欄 (データと索引簿が結びつかない) |
| `file_charset` | ファイル名の空白・`\ / : * ? " < > \|` |
| `file_dup` | 同じファイル名が2行以上 |
| `file_convention` | ファイル名に取引年月日 (YYYYMMDD) がない |
| `seq_gap` | 連番の飛び (行の欠落) |
| `retention_expired` | 取引年月日が7年より前 (法人税法上の保存期間は原則7年・欠損金の繰越がある事業年度は10年) |

## 同梱サンプルで測った数字

`_fixtures/clean.csv` (5行) → **0件**。`_fixtures/dirty.csv` (6行) → **14件**、内訳はエラー9件・警告5件で、**6行すべて**に直しが1つ以上つきます。どちらもこの拡張に入っているので、インストール直後に同じ数字を再現できます。

## いつ効くか

電子取引データの電子保存は **2024年1月**から宥恕期間が終わっています。隠蔽・仮装があった場合、電子取引データについては**重加算税が10%加重** (35% → 45%) されます。申告漏れ200万円に重加算税がかかる場面なら、加重分だけで **20万円**の上乗せです。索引簿が検索できないこと自体が即加算税ではありませんが、調査で「出せない」状態は、その手前の心証を作ります。

## 人に頼むといくらか

記帳代行・税務顧問に月次で頼むと月1万〜3万円が一般的な価格帯です。索引簿の形式チェックはその中の一部の作業で、月末にまとめて回ってきます。

## 使い方

1. 索引簿の CSV (または Markdown の表) を開く
2. コマンドパレット → `電帳法 索引簿リンター: Check this file`
3. 行番号つきで結果が出ます。`as of` の日付を変えると未来日・保存期間の判定が変わります
