# AI Act Article 50 Audit

![EU AI Act Article 50 Transparency Audit for Your Codebase](https://getreadystack.com/img/promo/sku17508_result_card.jpg)

Finds the AI call sites, generation code and system prompts that trigger EU AI Act Article 50 disclosure duties - in force since 2 August 2026.

## What it does for free

- Audit the open file against all 28 Article 50 rules, with line numbers
- Audit only the lines you highlight
- Reopen the last audit report
- List every rule and the Article 50 paragraph it maps to

## With a licence

- **Whole-repository audit** — Walks every file in the workspace instead of the one that is open, so the register covers the product you actually ship.
- **Export the register (CSV / JSON / HTML)** — Writes the findings to a file in your workspace, so you can attach the register to your Article 50 records.
- **CI report** — Writes a machine-readable JSON report so a pipeline can read it and gate a merge.
