# Outlook Split Lint

![Outlook Email HTML Lint - Classic vs New](https://getreadystack.com/img/promo/sku8261_result_card.jpg)

Classic Outlook renders with the Word engine, the new Outlook with WebView2. Lint one email file against both at once, line by line, before you send.

## What it does for free

- Check the open email file against both Outlook engines
- Check only the lines you select
- Reopen the last findings list
- List every rule that ships inside
