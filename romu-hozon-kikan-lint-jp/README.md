# 労務書類 保存期間チェック（法定帳簿の保存年数・起算日）

![労務書類 保存期間チェック](https://getreadystack.com/img/promo/sku284281_result_card.jpg)

社内の「文書保存期間表」「文書管理規程」の表（Markdown・CSV・テキスト）を開くと、賃金台帳・労働者名簿・出勤簿・健康診断個人票・雇用保険や社会保険の書類について、**法定の保存年数より短い行**、**起算日の誤り**、**法定の保存満了より前の廃棄予定日**を行番号つきで示します。

ツールページ: https://getreadystack.com/tools/romu-hozon-kikan-lint-jp

## 何を検査するか（20 rules）

| 書類 | 法定の保存期間 | 根拠 |
|---|---|---|
| 労働者名簿・賃金台帳・出勤簿／タイムカード・雇入れや退職の書類 | 原則5年（経過措置で当分の間3年） | 労基法109条・143条、労基則56条 |
| 年次有給休暇管理簿 | 原則5年（経過措置3年） | 労基則24条の7・72条 |
| 一般健康診断個人票・ストレスチェック結果・面接指導記録 | 5年 | 安衛則51条・52条の13・52条の6 |
| 労働時間の状況の記録（安衛法） | 3年 | 安衛則52条の7の3 |
| 安全・衛生委員会の議事録 | 3年 | 安衛則23条4項 |
| じん肺健康診断の記録 | 7年 | じん肺法17条 |
| 特別管理物質・電離放射線の健康診断個人票 | 30年 | 特化則40条2項・電離則57条 |
| 石綿健康診断個人票 | 40年 | 石綿則41条 |
| 雇用保険の被保険者に関する書類／その他の雇用保険書類 | 4年／2年 | 雇用保険法施行規則143条 |
| 労災保険・労働保険料に関する書類 | 3年 | 労災則51条・徴収則70条 |
| 健康保険・厚生年金保険に関する書類 | 2年 | 健保則34条・厚年則28条 |

このほか2つの規則があります。

- **起算日**: 労働者名簿の起算日を「作成日」「入社日」としている行を示します（起算日は退職・解雇・死亡の日。労基則56条）。
- **廃棄予定日**: 行に日付が2つあると、1つ目を起算日、2つ目を廃棄予定日として読み、起算日＋法定年数より前なら示します。基準日（今日）より前なら「既に廃棄期日を何日過ぎているか」も出します。

罰則のある書類には罰則も併記します。労基法109条違反は労基法120条で30万円以下（¥300,000以下）の罰金、安衛法103条の記録保存違反は安衛法120条で50万円以下（¥500,000以下）の罰金です。

## 例（同梱のサンプル「文書保存期間表（人事労務）」）

| 表に書かれていた行 | 法定 |
|---|---|
| 賃金台帳 2年 | 3年以上（原則5年）労基法109条 |
| 労働者名簿 起算＝作成日 | 起算＝退職・死亡の日 |
| 雇用保険被保険者資格取得届（控） 2年 | 4年 雇保則143条 |
| 一般健康診断個人票 3年 | 5年 安衛則51条 |
| 石綿健康診断個人票 5年 | 40年 石綿則41条 |
| 年次有給休暇管理簿 廃棄予定 2026-03-31 | 保存満了 2027-03-31（起算 2024-03-31＋3年） |

基準日 2026-09-25 で検査すると、上の6行が見つかります。健康保険の届出控2年・ストレスチェック5年・労働時間の状況の記録3年の行は正しいので何も出ません。

## 使い方

1. 保存期間表（.md / .csv / .txt）を開く。
2. 問題パネルに行ごとの指摘が出ます。コマンドパレットから再検査もできます。
3. 行の書き方は自由です。1行に書類名と「N年」があれば読めます（全角数字も可）。「永年」「永久」は常に適合です。

## 目安

社労士の顧問契約は小規模事業所でも月額¥20,000前後が一般的な相場です。このツールは顧問の代わりではなく、表の数字が条文と合っているかを先に確かめるためのものです。

## 注意

- 対象は厚生労働省所管の法令に基づく民間事業者の保存義務です。税法（法人税法の帳簿7年など）は対象外です。
- 経過措置（労基法143条）の「当分の間3年」は現在有効なので、3年と書いた行は指摘しません。メッセージには原則5年を併記します。
- 法令の改正で年数が変わることがあります。最終判断は条文と所轄の労働基準監督署・年金事務所・ハローワークで確認してください。
