# 派遣契約書チェック — 個別契約・就業条件明示書の記載事項

![派遣契約書チェック — 個別契約・就業条件明示書](https://getreadystack.com/img/promo/sku211276_result_card.jpg)

労働者派遣の**個別契約書**と**就業条件明示書**の下書き（.md / .txt）を開くと、派遣法26条1項・施行規則22条・34条の記載事項と照らし、**抜けている項目・空欄・古い用語**を行番号つきで「問題」パネルに出します。規則は28個、どれも条文番号と「直し方の例」つきです。

ブラウザ版（同じエンジン）：https://getreadystack.com/tools/haken-keiyaku-kisai-lint-jp

## なぜ要るのか

- 就業条件明示書では、事業所単位の抵触日・組織単位の抵触日・労働契約申込みみなし制度の旨を、派遣を始める**前に**明示します（派遣法34条1項3号・4号、3項）。34条の違反は派遣法61条3号で**30万円以下の罰金**（最大¥300,000）です。
- 個別契約書には、派遣法26条1項1～9号に加えて施行規則22条1～7号の事項が要ります。2020年以降の様式では「協定対象派遣労働者に限るか否かの別」（6号）と「無期雇用派遣労働者又は60歳以上の者に限るか否かの別」（7号）が抜けやすい項目です。
- 派遣法60条の刑は、2025年6月1日から「懲役」ではなく「拘禁刑」です。古い雛形を流用すると、この一語が残ります。

厚生労働省の記載例は見本であり、あなたの下書きのどの行が抜けているかは教えてくれません。このツールは、その下書きそのものを読みます。

## 使い方

1. 契約書の下書きを Markdown かテキストで開く
2. 保存するたびに検査が走り、「問題」パネルに行番号つきで出る
3. 見出しや本文に「就業条件明示」と書いてあれば、抵触日・みなし制度の3規則も自動で加わる。「紹介予定派遣」と書いてあれば、不採用理由の明示の規則が加わる

サンプルの就業条件明示書（`_fixtures/dirty.md`）では、エラー9件・警告4件が出ます。
