# HTML Tag Inserter: Accessible ARIA + WCAG 2.2

36 accessible HTML tag patterns and 20 WCAG 2.2 checks that run offline on the file you have open. An accessibility reviewer never reads your CSS — they tab through your landmarks, your labels and your alt text, and every tag they look for is in this pack.

## What it does for free

- A complete WCAG 2.2 audit of the file you have open, with line numbers
- All 36 accessible tag patterns, inserted at the cursor
- The full list of 20 rules and 36 patterns, readable before you run anything

## With a licence

- **Every template in the repository, not only the file on screen** — Opens every file in the workspace and runs the same check on each.
- **The report file your reviewer signs off on** — Writes the findings as a file (CSV, JSON or HTML) into the workspace folder; it uses the report_format setting when that is set, and only asks which format when it is not.
- **Fix the flagged lines in the editor instead of retyping them** — Replaces the offending lines in the editor with the suggested text.
- **It stays clean, because every save is checked again** — A toggle: after it is on, every save re-runs the check.

## Install

```
ext install html-tag-inserter-accessible-aria
```
