# Jest Snippets + 7 More Stacks (40 Snippets)

One fit( merged into main turns a green suite into a single passing test. 20 checks find it in the file you have open, before the reviewer does.

## What it does for free

- All 40 snippets across 8 stacks, no key and no limit
- All 20 checks on the file you have open, with file and line number
- The same 20 checks on just the lines you selected
- The full list of what ships inside, readable before you trust it

## With a licence

- **Every file in the repository, not just the one on screen** — Opens every file in the workspace and runs the same check on each.
- **A report file you can attach to the pull request** — Writes the findings as a file (CSV, JSON or HTML) into the workspace folder; it uses the report_format setting when that is set, and only asks which format when it is not.
- **Turn fit( back into it( in place** — Replaces the offending lines in the editor with the suggested text.

## Install

```
ext install jest-snippets-8-stacks
```
