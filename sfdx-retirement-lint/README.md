# SFDX Retirement Lint

![Salesforce API Version & CLI Retirement Lint](https://getreadystack.com/img/promo/sku19684_result_card.jpg)

Finds retired API versions and removed sfdx force:* commands in your DX repo before a deploy or a CI run fails with 410 GONE.

## What it does for free

- Check the open file end to end - every rule, every line, no key asked.
- Check just the lines you selected.
- Read all 81 rules with the retirement date and error code each one cites.

## With a licence

- **Scan the whole repository** — One command over every -meta.xml, package.xml, sfdx-project.json and CI script in the workspace instead of the file you happen to have open.
- **Rewrite the removed commands and flags** — Applies the sf-style replacement for the command and flag rules. Version numbers are reported for a manual edit, never rewritten - bumping an API version is a judgement call and we will not silently change your metadata.
- **Machine output for CI** — JSON your pipeline can read, so a retired version fails the build, not the deploy.
- **Export the findings** — Writes CSV, JSON or HTML into the workspace so you can hand the list to a team.
