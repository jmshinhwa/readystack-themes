# Runtime EOL Guard

![Runtime EOL and Deploy-Block Audit for Docker, CI and AWS Lambda](https://getreadystack.com/img/promo/sku24417_result_card.jpg)

Finds the end-of-life runtimes an AI assistant still writes for you — node:20, python3.9, ubuntu-22.04, nodejs20.x — and prints the exact date each one stops deploying.

## What it does for free

- Check the open file against all 54 rules — no key, no cap, no watermark
- Check only the lines you select
- Every finding carries its real EOL date and the deploy-block date
- List all 54 rules and the version each one replaces
- Reopen the last report any time

## With a licence
