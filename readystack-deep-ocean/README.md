# ReadyStack Deep Ocean

Submarine blues with aqua accents. Reads cool and quiet at any hour.

## Install

1. Open the Extensions view
2. Search **ReadyStack Deep Ocean**
3. Install, then `Ctrl+K Ctrl+T` and pick it

## Measured contrast

| element | ratio | standard |
|---|---|---|
| body text | 14.3:1 | WCAG AAA (7:1) |
| keywords | 9.9:1 | WCAG AA (4.5:1) |
| strings | 10.4:1 | WCAG AA (4.5:1) |
| comments | 3.7:1 | deliberately receding |

Every ratio above was measured, not estimated.

## What is tuned

- **Comments** muted and italic - they should not compete with code
- **Strings** and **numbers** are different colors - two kinds of literal, two signals
- **Keywords** bold - the shape of the code reads at a glance
- **Terminal** ANSI colors match the editor, so output does not clash
- **Git decorations** follow the same palette

## Your terminal is still the wrong color

This theme colors the editor. The moment you open a terminal outside VS Code -
iTerm2, Windows Terminal, Alacritty, kitty - it is still on its old palette,
and so is every other window you work in.

**ReadyStack Deep Ocean - Full Environment** ships the same measured palette as ready-to-import
profiles for all four terminals, plus the source palette as JSON so you can
carry it into anything else. One palette, every window.
