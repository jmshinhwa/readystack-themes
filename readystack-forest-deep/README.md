# ReadyStack Forest Deep

Dark forest green with lime accents. Low blue light, easy on long reviews.

## Install

1. Open the Extensions view
2. Search **ReadyStack Forest Deep**
3. Install, then `Ctrl+K Ctrl+T` and pick it

## Measured contrast

| element | ratio | standard |
|---|---|---|
| body text | 14.2:1 | WCAG AAA (7:1) |
| keywords | 11.0:1 | WCAG AA (4.5:1) |
| strings | 10.3:1 | WCAG AA (4.5:1) |
| comments | 3.8:1 | deliberately receding |

Every ratio above was measured, not estimated.

## What is tuned

- **Comments** muted and italic - they should not compete with code
- **Strings** and **numbers** are different colors - two kinds of literal, two signals
- **Keywords** bold - the shape of the code reads at a glance
- **Terminal** ANSI colors match the editor, so output does not clash
- **Git decorations** follow the same palette
