Python Log Leak Lint: PCI DSS Card Data — Licence

Free scope
  Checks the open Python file against 10 rules and lists every log, print or raise line that writes card data or credentials, with line number, PCI DSS v4.0.1 requirement and fix. Complete for free. is free for any use, personal or commercial, for as long as you keep the
  extension installed, and the online check at the product page is free without registration.

Paid scope
  Scans every .py file in the repository in one run and exports the findings as a Markdown evidence table for your PCI DSS assessment. is the paid part. It asks for a licence key issued at purchase (one seat, one key). The key is checked against the payment provider and
  cached locally for 30 days so it keeps working offline.
