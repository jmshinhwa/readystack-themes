会計ソフトから書き出した **固定資産台帳 CSV** を開くと、少額減価償却資産の特例（租税特別措置法28条の2・67条の5）と法人税法施行令133条・133条の2に照らして、行ごとの誤りを「問題」パネルに行番号つきで出します。

無料ウェブ版（同じ判定エンジン）：https://getreadystack.com/ja/tools/kotei-shisan-daicho-csv-lint

判定の物差し：措法67条の5・法令133条・法令133条の2・令和8年度税制改正（2026-09-28 時点の条文と大綱）。

## なぜ必要か

令和8年度税制改正で、中小企業者等の少額減価償却資産の特例は **2026-04-01 以後に取得した資産から上限が30万円未満→40万円未満** になりました。年間合計300万円の枠は変わりません。対象法人は常時使用する従業員 **400人以下**（改正前は500人以下）に絞られました。

つまり12月決算や9月決算の会社では、**同じ事業年度の台帳に「30万円未満まで」の行と「40万円未満まで」の行が混ざります**。¥350,000 のノートPCは 2026-04-15 取得なら特例の対象、2026-02-10 取得なら対象外です。さらに300万円枠は取得価額の累計で判定し、枠を超えさせる資産は **丸ごと** 特例の対象外になります。

## 検査する10項目

| ID | 内容 | 根拠 |
|---|---|---|
| SG01 | 取得日で上限を切り替え（2026-03-31以前は30万円未満・2026-04-01以後は40万円未満） | 措法28条の2・67条の5 |
| SG02 | 年300万円枠（短い事業年度は月数で按分）を超えさせる資産 | 措法67条の5① |
| SG03 | 10万円未満の資産を特例に入れて枠を消費している | 法令133条 |
| SG04 | 一括償却資産は20万円未満のみ | 法令133条の2 |
| SG05 | 即時損金は10万円未満のみ | 法令133条 |
| SG06 | 貸付の用に供した資産（主要な事業としての貸付を除く） | 令和4年度改正 |
| SG07 | 従業員数要件（2026-04-01以後取得は400人以下、それ以前は500人以下） | 措法67条の5 |
| SG08 | 取得日・取得価額が読めない行 | 台帳の記載 |
| SG09 | 別表十六（七）の添付が適用要件 | 措法67条の5③ |
| SG10 | 特例で損金にした10万円以上の資産も償却資産税の申告対象 | 地方税法341条・383条 |

## CSV の形

1行目（`#` 行を除く）が見出しです。列名は次の語を含めば自動で見つけます：`資産名`・`取得日`（`令和8年3月20日` や `R8.3.20` も可）・`取得価額`・`区分`（「少額特例」「一括償却」「即時」「通常償却」）・`用途`。

台帳の先頭に次の行を書くと判定に使います：

```
# 事業年度: 2026-01-01〜2026-12-31
# 従業員数: 45
# 明細書: 添付
# 償却資産申告: 済
```

## 実測（同梱のサンプル台帳 _fixtures/dirty.csv・12月決算・従業員45人）

- 10件を検出（エラー5・警告3・情報2）
- 特例の対象外になる取得価額の合計 **¥1,050,000**（ノートPC A ¥350,000・ルーター ¥320,000 は2026-04-01より前の取得、ノートPC E ¥380,000 は累計 ¥3,271,800 で枠 ¥3,000,000 超）
- 同じ台帳の従業員数を450人にすると、2026-04-01以後に取得した特例の行が SG07 で対象外になります
