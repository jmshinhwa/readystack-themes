# E-Invoice Lint

![E-Invoice Lint for XRechnung, Factur-X and UBL](https://getreadystack.com/img/promo/sku14679_result_card.jpg)

Catches retired profile identifiers, code-list values outside EN 16931 and malformed dates in your e-invoice XML, in the editor, before an access point rejects the file.

## What it does for free

- Check the open e-invoice against all 26 rules
- Check only the lines you select
- Reopen the last findings, with line numbers and severity
- Read every rule that ships inside, in plain English

## With a licence

- **Check every e-invoice file in the repository** — One pass over every XML in the project - fixture files, templates and generated output - instead of the one that happens to be open.
- **Findings report as CSV, JSON or HTML** — Writes the findings to a file you can attach to a release, hand to the integration owner or keep with the test evidence.
- **JSON output a build step can fail on** — Machine-readable findings so a pipeline blocks the merge that would have shipped a rejected invoice.
