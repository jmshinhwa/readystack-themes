# 年末調整 扶養控除 チェック（令和8年分・62万円）

![年末調整 扶養控除 チェック（令和8年分・62万円）](https://getreadystack.com/img/promo/sku277662_result_card.jpg)

年末調整の扶養親族CSV（扶養控除等申告書のデータ）を、令和8年分の新しい要件で1行ずつ判定する VS Code 拡張です。CSVを開くと、控除漏れ・過大控除・未回収の書類が行の上に出ます。

無料のウェブ版（同じ判定エンジン）：https://getreadystack.com/ja/tools/nencho-fuyo-csv-lint-r8

## 令和8年分で変わったこと（国税庁タックスアンサーで確認）

令和8年12月1日に施行され、令和8年分から適用されます。つまり今年の年末調整から効きます。

| 項目 | 令和7年分 | 令和8年分 |
|---|---|---|
| 扶養親族・配偶者控除の合計所得要件 | 58万円以下 | 62万円以下 |
| 配偶者特別控除の範囲 | 58万円超133万円以下 | 62万円超133万円以下 |
| 特定親族特別控除の範囲（19〜22歳） | 58万円超123万円以下 | 62万円超123万円以下 |
| 給与所得控除の最低額 | 65万円 | 74万円 |
| 配偶者の給与収入の目安（配偶者控除） | 123万円以下 | 136万円以下 |

出典：No.1180 扶養控除、No.1191 配偶者控除、No.1195 配偶者特別控除、No.1177 特定親族特別控除、No.1410 給与所得控除（国税庁）。

## 検査する19ルール

1. 16歳未満を扶養控除に入れている（年少扶養）
2. 特定扶養の年齢（12/31現在19歳以上23歳未満）を外れている
3. 老人扶養・同居老親なのに70歳未満
4. 70歳以上なのに一般扶養のまま（老人扶養48万円・同居老親58万円の漏れ）
5. 同居老親の要件（直系尊属・同居）を満たさない
6. 扶養親族の合計所得が62万円を超えている
7. 合計所得が令和8年分の給与所得控除（最低74万円）で計算されていない
8. 所得62万円以下・16歳以上なのに扶養控除の対象外
9. 19〜22歳・所得62万円超123万円以下なのに特定親族特別控除がない
10. 特定親族特別控除の範囲外
11. 配偶者控除なのに配偶者の所得が62万円超
12. 配偶者特別控除の範囲（62万円超133万円以下）外
13. 配偶者の所得133万円以下なのに配偶者の控除がない
14. 国外居住の30〜69歳で、留学・障害者・送金38万円以上のどれにも当たらない
15. 国外居住親族の親族関係書類が未回収
16. 国外居住親族の送金関係書類（38万円送金書類）が未回収
17. 留学で国外居住の30〜69歳の留学ビザ等書類
18. 1月1日生まれの年齢（12/31に1歳上になる）
19. 列の欠け・読めない日付や金額

各行に、正しい区分・控除額・根拠条文（所得税法83条・83条の2・84条・84条の2 など）を出します。最後に「控除漏れ ¥…・過大控除 ¥…」の合計を1行出します。

## CSVの形

```
氏名,続柄,生年月日,同居,国外,区分,合計所得,給与収入,障害者,留学,送金額,親族関係書類,送金関係書類
佐藤 翔,子,2006-06-11,有,無,対象外,1060000,1800000,無,無,0,,
```

区分は 一般扶養・特定扶養・老人扶養・同居老親・特定親族・配偶者控除・配偶者特別控除・年少・対象外 のどれか。金額は円（「62万」も可）。給与収入があれば、令和8年分の給与所得控除で合計所得を引き直して判定します。

## サンプルでの結果

同梱の `_fixtures/dirty.csv`（サンプル7人）では、11件の指摘が出て、控除漏れ ¥1,170,000・過大控除 ¥860,000 でした。たとえば 20歳・給与¥1,800,000 の子は所得¥1,060,000 で、扶養からは外れても特定親族特別控除 ¥210,000 が付きます。1957年1月1日生まれの父は 2026年12月31日に70歳になり、同居なら同居老親 ¥580,000 です。

## 前提と限界

- 本人（従業員）の合計所得は900万円以下として控除額を出します。900万円超の配偶者控除・配偶者特別控除の減額は反映しません。
- 障害者控除・寡婦・ひとり親控除は判定しません。
- 判定は申告書データの整合チェックです。最終判断は税務署・税理士の確認を優先してください。

## 物差し

税理士に年末調整を頼んだ実例：従業員1人あたり2,500円（従業員45名で11万2,500円・税理士ドットコム掲載の事例）
