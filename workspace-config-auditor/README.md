# Angular CLI Workspace Config Auditor

32 snippets and 25 audit rules for the 8 config files an Angular workspace actually ships with. Your components pass review; a hard-coded IoT device key, an absolute backend URL in manifest.json, or a coverage threshold of 0 is what fails it.

## What it does for free

- Full audit of the file you have open, all 25 rules, no key
- Audit only the lines you selected
- All 32 snippets, insertable at the cursor
- The complete rule and snippet list, readable before you buy

## With a licence

- **Whole-workspace scan** — Opens every file in the workspace and runs the same check on each.
- **Report export** — Asks CSV, JSON or HTML, then writes that file into the workspace folder.
- **Apply suggested replacement** — Replaces the offending lines in the editor with the suggested text.

## Install

```
ext install workspace-config-auditor
```
