給与計算の設定ファイルやソースに、令和7年度以前の雇用保険料率が残っていないかを1行ずつ調べる VS Code 拡張です。YAML・JSON・CSV・TypeScript・JavaScript・Python を読みます。

ツールの説明とブラウザ版: https://getreadystack.com/ja/tools/koyo-hoken-ryoritsu-lint-r8

## 何が変わったか (令和8年4月1日〜令和9年3月31日)

厚生労働省「令和８（2026）年度 雇用保険料率のご案内」の表そのままです。

| 事業の種類 | 労働者負担 | 事業主負担 | 雇用保険料率 | 令和7年度 |
|---|---|---|---|---|
| 一般の事業 | 5/1,000 | 8.5/1,000 | 13.5/1,000 | 14.5/1,000 (労働者5.5/1,000) |
| 農林水産・清酒製造の事業 | 6/1,000 | 9.5/1,000 | 15.5/1,000 | 16.5/1,000 (労働者6.5/1,000) |
| 建設の事業 | 6/1,000 | 10.5/1,000 | 16.5/1,000 | 17.5/1,000 (労働者6.5/1,000) |

雇用保険二事業の率 (事業主のみ) は 3.5/1,000 のまま、建設の事業は 4.5/1,000 のままです。令和5・6年度は一般の事業 15.5/1,000 (労働者6/1,000) でした。

## 6つのルール

1. **ei-rate-stale-general** — 一般の事業で令和7年度・令和5〜6年度の率 (14.5・5.5・9・15.5・6・9.5 /1,000) が現行値として書かれている行。
2. **ei-rate-stale-agri** — 農林水産・清酒製造の事業で旧率 (16.5・6.5・10・17.5・7・10.5 /1,000)。
3. **ei-rate-stale-construction** — 建設の事業で旧率 (17.5・6.5・11・18.5・7・11.5 /1,000)。
4. **ei-over64-exemption** — 64歳以上の保険料免除ロジック。免除は令和2年3月分で終わり、令和2年4月以降は64歳以上も徴収します。
5. **ei-rounding-half** — 労働者負担額の端数処理に Math.round や round を使っている行。賃金から控除する場合は50銭以下切り捨て・50銭超切り上げです。
6. **ei-hours-threshold-2028** — 週20時間の加入要件をハードコードした行 (情報)。2028年10月1日から週10時間以上に変わります。

料率は `0.0055`・`5.5/1000`・`5.5/1,000`・`1000分の5.5`・`5.5‰`・`0.55%` のどの書き方でも読みます。業種は `construction:` や `建設` のような見出しから引き継ぎます。

## 履歴テーブルは対象外

給与システムは過去の率を適用開始日付きで持つのが普通です。同じ行か直前2行に 2026-04-01 より前の日付 (`from: "2025-04-01"` など) や「令和7年度」と書かれていれば、その行は過去分として扱い、指摘しません。単純な文字列検索では、この履歴行と現行行の区別がつきません。

## 例

```yaml
koyo_hoken:
  general:
    employee: 0.0055   # ← ei-rate-stale-general: 令和8年度は 5/1,000
```

月給¥300,000 の人なら労働者負担は ¥1,650 から ¥1,500 に下がります。1人あたり月¥150、100人・4〜9月分の6か月で ¥90,000 を控除しすぎた計算になり、差額の返金と再計算が必要です。

## 使い方

- ファイルを開くと自動で検査し、問題の行に波線と説明が出ます。
- コマンドパレット: 「koyoRyoritsu」で始まるコマンドから、開いているファイルを検査できます。
- 無料で、開いている1ファイルに6ルールすべてを適用し、正しい令和8年度の値まで表示します。
- ワークスペース全体の一括検査と監査用 CSV/Markdown 報告書の書き出しはライセンスキーで使えます: https://buy.polar.sh/polar_cl_H21NzxFebYKqtlsCmGjXAtBaOkc6bP6Lix19i3KELMV

## 目安

給与計算の外部委託は、従業員30〜100名で月¥50,000〜¥150,000 が相場とされています (給与計算アウトソーシング各社の比較記事による)。
