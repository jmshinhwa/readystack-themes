# 請求書インボイス チェッカー（適格請求書・端数処理）

![請求書インボイス チェッカー（適格請求書・端数処理）](https://getreadystack.com/img/promo/sku218176_result_card.jpg)

2026年10月1日から、適格請求書でない請求書を受け取った買手の控除は **80% → 70%** に下がります。登録番号が1桁欠けただけの請求書は適格請求書になりません。この拡張は、あなたのシステムが出力する請求書（.md / .html / .txt）を開いた瞬間に、記載事項の欠けと消費税の端数処理の誤りを行番号つきで示します。

ハブ: https://getreadystack.com/tools/tekikaku-seikyusho-lint-jp

## 何を検査するか（13 rules）

| ID | 内容 | 根拠 |
|---|---|---|
| INV-REG-MISSING | 登録番号（T+13桁）がない | 消費税法57条の4第1項第1号 |
| INV-REG-FORMAT | 登録番号の桁数・全角文字 | 同 第1号 |
| INV-REG-PENDING | 「申請中」「取得予定」のまま | 同 第1項 |
| INV-DATE-MISSING | 取引年月日がない | 同 第2号 |
| INV-BUYER-MISSING | 宛名（御中・様）がない | 同 第6号 |
| INV-RATE-MISSING | 適用税率（10%・8%）がない | 同 第4号 |
| INV-REDUCED-MARK | 軽減税率対象である旨がない | 同 第3号 |
| INV-TAX-PER-RATE | 税率ごとの対象額・消費税額がない | 同 第4号・第5号 |
| INV-LINE-TAX | 品目ごとの端数処理 | 消費税法施行令70条の10 |
| INV-BASE-MISMATCH | 税率別の対象額 ≠ 品目の合計 | 同 第4号 |
| INV-TAX-MISMATCH | 消費税額 ≠ 税率ごと1回の端数処理 | 施行令70条の10 |
| INV-TOTAL-MISMATCH | 合計 ≠ 対象額 + 消費税額 | 同 第4号 |
| INV-KEIKA-80 | 2026年10月1日以降の取引に「80%控除」 | 平成28年改正法附則52条・53条（令和8年度改正） |

## サンプル請求書での結果

同梱の `_fixtures/dirty.md`（2026年10月15日発行・Webサイト改修など4品目）を開くと 6件（エラー5・警告1）が出ます。

- 登録番号 `T123456789012` は数字12桁。買手は消費税 ¥22,806 のうち 30%（¥6,841）を控除できない（経過措置 70%）
- 品目ごとに切捨てた消費税の合計は ¥22,806。税率ごと1回の切捨てなら ¥22,807（10%対象 ¥222,030 → 消費税 ¥22,203、8%対象 ¥7,553 → 消費税 ¥604）
- 弁当（8%）に軽減税率対象である旨がない
- 10%・8%の区分ごとの消費税額がない
- 品目行に消費税列がある（行ごとの端数処理）
- 「80%控除が受けられます」と書いているが、2026年10月15日の取引は70%控除

同じ請求書の日付を2026年9月25日に変えると 5件で、控除できないのは 20%（¥4,561・経過措置 80%）です。

直した `_fixtures/clean.md` は 0件です（合計 ¥252,390 = ¥222,030 + ¥7,553 + ¥22,203 + ¥604）。

請求書に日付がないときは、今日の日付で判定します。

## 使い方

1. 請求書テンプレートや出力ファイル（.md / .html / .txt）を開く
2. 問題パネルに行番号つきで表示される
3. コマンドパレット「請求書インボイス チェッカー」から再検査

HTML の請求書はタグを外して表として読みます。金額は「¥12,345」「12,345円」の形を読み取ります。税込表示（「税込」のみ）のときは 10/110・8/108 で消費税額を確かめます。

## なぜチャットAIや目視では足りないか

チャットAIは請求書の見た目を整えますが、品目ごとの端数処理と税率ごと1回の端数処理の ¥1 の差や、2026年10月1日の70%への切替を取りこぼします。この拡張はファイルの数字そのものを計算し直します。
