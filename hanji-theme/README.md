# Hanji — code on paper

![Hanji Day, Hanji Ink and Hanji Lamplight side by side](https://raw.githubusercontent.com/jmshinhwa/readystack-themes/main/hanji-theme/family.jpg)

**Three warm, low-glare themes in one extension: Day, Ink and Lamplight.**
Hanji is Korean mulberry paper, made by hand for a thousand years: warm, soft and easy on the eyes. This theme brings that paper, its ink and the old natural dyes to your editor: indigo, pine, safflower red, ochre, celadon and gromwell purple.

Every colour in your code is measured against its background. Body text passes WCAG AAA, and every syntax colour passes AA, **comments included**. Many themes fade comments below readable contrast. Hanji doesn't.

| Variant | Body text | Lowest syntax colour | Comments |
|---|---|---|---|
| Hanji Day (light) | 12.6:1 | 5.0:1 | 4.6:1 |
| Hanji Ink (dark) | 13.1:1 | 7.5:1 | 5.1:1 |
| Hanji Lamplight (dim) | 11.1:1 | 7.0:1 | 4.9:1 |

## Install

1. Open the Extensions view (`Ctrl+Shift+X`, or `Cmd+Shift+X` on macOS) and search **Hanji**
2. Install, then press `Ctrl+K Ctrl+T` (`Cmd+K Cmd+T` on macOS)
3. Pick **Hanji Day**, **Hanji Ink** or **Hanji Lamplight**
