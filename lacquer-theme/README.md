# Lacquer — Black lacquer, vermilion, gold leaf and abalone shell inlay

![Lacquer variants side by side](https://raw.githubusercontent.com/jmshinhwa/readystack-themes/main/lacquer-theme/family.jpg)

**Three themes in one extension: Lacquer Black, Lacquer Abalone, Lacquer Gold.**
A lacquer box is built up coat by coat until its surface goes deep and still, then decorated with vermilion, sprinkled gold and slivers of abalone shell. Lacquer brings that box into the editor: a warm red-black ground, a cool shell-blue night, and a pale gold-leaf day. The grounds stay low-glare, and each syntax role gets its own pigment, so keywords, strings and numbers never melt into one another.

Every colour in your code is measured against its background. Body text passes WCAG AAA, and every syntax colour passes AA, **comments included**.

| Variant | Body text | Lowest syntax colour | Comments |
|---|---|---|---|
| Lacquer Black (dark) | 14.4:1 | 6.3:1 | 5.3:1 |
| Lacquer Abalone (dark) | 14.2:1 | 6.6:1 | 5.5:1 |
| Lacquer Gold (light) | 14.0:1 | 5.4:1 | 5.4:1 |

Tuned for JavaScript, TypeScript, Python, Go, Rust, Markdown, JSON, YAML, HTML and CSS, with semantic highlighting on. The terminal's 16 colours, git decorations, diffs and bracket pairs all use the same palette.

## Install

1. Open the Extensions view (`Ctrl+Shift+X`, or `Cmd+Shift+X` on macOS) and search **Lacquer**
2. Install, then `Ctrl+K Ctrl+T` (or `Cmd+K Cmd+T`) and pick Lacquer Black / Lacquer Abalone / Lacquer Gold.
