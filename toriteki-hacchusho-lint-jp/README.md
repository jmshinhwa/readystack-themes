## 何が変わったか（2026年1月1日から）

- 手形による支払が禁止された。手形の交付は支払遅延に含まれる（第5条第1項第2号）。電子記録債権やファクタリングも、支払期日までに代金全額の金銭に換えにくいものは同じ扱い。
- 支払期日は、検査をするかどうかを問わず給付の受領日から60日以内（第3条第1項）。60日を超えて定めると、60日目が支払期日とみなされる（第3条第2項）。
- 受託側が代金の協議を求めたのに応じず、一方的に代金を決めることが禁止された（第5条第2項第4号）。
- 適用基準に従業員数が加わった。製造委託等は常時使用する従業員300人超の法人から300人以下の事業者へ、情報成果物作成委託・役務提供委託は100人超から100人以下へ（第2条）。
- 用語が「親事業者→委託事業者」「下請事業者→中小受託事業者」「下請代金→製造委託等代金」に変わった。
- 明示義務（旧「3条書面」）は第4条になり、電磁的方法でも明示できる。受託側から書面を求められたら交付する（第4条第2項）。
- 第4条の明示をしなかったときは、違反者と会社（両罰・第16条）に¥500,000（50万円）以下の罰金（第14条）。
