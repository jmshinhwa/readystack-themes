# Saltmarsh — Estuary colours: sea lavender, cordgrass, samphire, tide

![Saltmarsh variants side by side](https://raw.githubusercontent.com/jmshinhwa/readystack-themes/main/saltmarsh-theme/family.jpg)

**Three themes in one extension: Saltmarsh Tide, Saltmarsh Dusk, Saltmarsh Haar.**
Saltmarsh is the edge of an estuary at low tide: sea lavender in flower, cordgrass gone to straw, samphire reddening on the mud, and the channel water holding the sky. Keywords take the lavender, strings the straw, numbers the samphire, types the tide water. Grounds are muted fog, channel slate or dusk brown, never pure black or white, and every syntax colour clears WCAG AA against them, so long sessions stay low-glare.

Every colour in your code is measured against its background. Body text passes WCAG AAA, and every syntax colour passes AA, **comments included**.

| Variant | Body text | Lowest syntax colour | Comments |
|---|---|---|---|
| Saltmarsh Tide (dark) | 12.7:1 | 6.8:1 | 5.5:1 |
| Saltmarsh Dusk (dark) | 12.4:1 | 7.2:1 | 5.4:1 |
| Saltmarsh Haar (light) | 11.6:1 | 5.0:1 | 4.8:1 |

Tuned for JavaScript, TypeScript, Python, Go, Rust, Markdown, JSON, YAML, HTML and CSS, with semantic highlighting on. The terminal's 16 colours, git decorations, diffs and bracket pairs all use the same palette.

## Install

1. Open the Extensions view (`Ctrl+Shift+X`, or `Cmd+Shift+X` on macOS) and search **Saltmarsh**
2. Install, then `Ctrl+K Ctrl+T` (or `Cmd+K Cmd+T`) and pick Saltmarsh Tide / Saltmarsh Dusk / Saltmarsh Haar.
