# 給与計算 健康保険料率・支援金チェッカー 令和8年度

![給与計算 健康保険料率・支援金チェッカー 令和8年度](https://getreadystack.com/img/promo/sku362814_result_card.jpg)

健康保険料率 令和8年度の値と子ども・子育て支援金 0.23% を、給与計算の設定ファイルとソースの中で1行ずつ照合する VS Code 拡張です。YAML・JSON・CSV・TS・JS・Python を開くと、令和7年度の料率が残っている行に波線が付き、その都道府県の令和8年度の値が横に出ます。

ブラウザ版(同じ判定エンジン): https://getreadystack.com/tools/shaho-ryoritsu-lint-r8

## 何が変わったか (協会けんぽ 保険料額表で確認)

- 健康保険料率(都道府県単位保険料率)は令和8年3月分(4月納付分)から改定。47都道府県のうち多くが下がりました。例: 東京 9.91% → 9.85%、大阪 10.24% → 10.13%、福岡 10.31% → 10.11%、佐賀 10.78% → 10.55%。
- 介護保険料率は令和8年3月分から 1.59% → 1.62%。
- 子ども・子育て支援金 0.23% (労使折半で本人 0.115%) が令和8年4月分(5月納付分)から始まりました。健康保険料と一緒に納付します。
- 子ども・子育て拠出金 0.36% (事業主のみ・令和2年4月分〜) と厚生年金保険料率 18.3% (平成29年9月分〜) は据え置き。
- 標準報酬月額の上限は健康保険 ¥1,390,000 (第50級)、厚生年金 ¥650,000 (第32級)。

| shienkin-rate | 支援金率が 0.23% (折半 0.115%) ではない |
| shienkin-kyoshutsu-mixup | 支援金と拠出金 0.36% の取り違え |

料率は 0.0985・9.85%・98.5/1000 のどの書き方でも読み、折半の値(4.925% など)も正しく扱います。YAML/JSON の入れ子(health_insurance: の下の tokyo: など)と、見出し行つきの CSV に対応します。都道府県は漢字(東京都・京都府)とローマ字(tokyo・kyoto)の両方を認識します。

## 例: 同梱のサンプル設定で出る6件

東京 0.0991・大阪 0.1024・介護 0.0159・拠出金欄の 0.0023・厚生年金上限 620000 と、支援金の行の欠落。修正後のサンプルは0件です。

## なぜ放置すると損か

社会保険料は日本年金機構の納入告知で標準報酬月額どおりに請求されるため、給与側の設定が古くても会社は正しい額を納めます。差は会社の持ち出しか、社員からの取りすぎになります。しかも給与から控除できるのは前月分の保険料だけです (健康保険法第167条)。

試算: 東京・標準報酬月額 ¥300,000 の社員の支援金本人負担は月 ¥345。支援金の設定がないまま100人・4月分〜9月分の6か月で ¥207,000 を会社が負担したことになります。同じ社員(介護該当)の健康保険+介護の本人負担は令和7年度 ¥17,250、令和8年度 ¥17,205 で、月 ¥45 の取りすぎです。

## 無料と有料

無料: 開いている1ファイルを全14ルールで検査し、正しい値をその場で表示します。これだけで1つの設定ファイルの見直しは完了します。

## 根拠

- 全国健康保険協会「令和8年3月分(4月納付分)からの健康保険・厚生年金保険の保険料額表」(r8ippan3.xlsx) — 47都道府県の料率、介護 1.62%、支援金 0.23%、拠出金 0.36%
- 同「令和7年3月分からの保険料額表」(r7ippan3.xlsx) — 旧料率
- 健康保険法第167条 (保険料の源泉控除)

この拡張は協会けんぽ(全国健康保険協会管掌)の料率を対象にします。健康保険組合の料率は組合ごとに違うため、組合の値は判定しません。
