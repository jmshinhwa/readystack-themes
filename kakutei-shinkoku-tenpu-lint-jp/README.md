確定申告の準備メモ（Markdown / テキスト）を開くと、控除ごとに必要な添付書類が揃っているか、不要な書類を添付しようとしていないかを、行番号つきで問題パネルに表示する VS Code 拡張です。17 rules。ハブ: https://getreadystack.com/ja/tools/kakutei-shinkoku-tenpu-lint-jp

同梱のサンプルメモ（令和8年分・フリーランス エンジニア・郵送提出）では **8件**（エラー6件・警告2件）を検出し、控除 **¥398,420**（国民年金保険料 ¥210,120 ＋ 生命保険料控除 ¥40,000 ＋ 医療費控除 ¥148,300）に必要な証明書・明細書がないことを示します。

## 何を検査するか

| 規則 | 見る場所 | 根拠 |
|---|---|---|
| 源泉徴収票・特定口座年間取引報告書の添付は不要 | 添付書類の見出しの下 | 2019年4月1日以後に提出する申告書から添付不要 |
| 医療費控除の明細書（領収書は代わりにならない） | 医療費控除の行 | 所得税法120条・令和2年分以後は領収書の添付による代用不可 |
| 国民年金保険料・国民年金基金の控除証明書 | 社会保険料控除の行 | 所得税法120条・施行令262条 |
| 国民健康保険税（料）の納付証明書は添付不要 | 添付書類 | 施行令262条 |
| 生命保険料・地震保険料・小規模企業共済・iDeCo の証明書 | 各控除の行 | 所得税法120条・施行令262条 |
| 寄附金受領証明書の枚数と寄附件数 | 寄附金控除の行 | 所得税法120条・施行令262条 |
| 確定申告をするとワンストップ特例は使えない | 「ワンストップ」の行 | 地方税法附則7条 |

| 決算書・収支内訳書 | 事業所得・不動産所得の行 | 所得税法149条・120条 |

## メモの書き方

```markdown
# 令和8年分 確定申告メモ
提出方法: 郵送
提出予定日: 2027年3月10日

## 控除
- 社会保険料控除（国民年金保険料）: ¥210,120
- 医療費控除: 控除額 ¥148,300

## 添付する書類
- 医療費の領収書 42枚
```

見出しに「添付」「提出書類」「用意」を含む節を添付書類の一覧として読み、それ以外の行を所得・控除として読みます。年分は「令和8年分」または「2026年分」から取り、法定申告期限を計算します（令和8年分は2027年3月15日）。

## 使い方

1. 準備メモ（.md / .txt）を開く — 保存するたびに自動で検査します。
2. コマンドパレットから「確定申告 添付書類チェッカー: 検査」でも実行できます。
3. 問題パネルの各行に、規則・根拠・直し方が出ます。
