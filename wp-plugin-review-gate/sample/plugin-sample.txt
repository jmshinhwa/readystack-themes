Speedy SEO Toolkit adds sitemaps, schema output, meta tag control, redirects, breadcrumbs and a readable on-page score to your WordPress site, with no configuration needed at all.

== Description ==

Sitemaps, schema, meta tags and redirects in one plugin.

== Installation ==

1. Upload the folder to wp-content/plugins.
2. Activate the plugin.
