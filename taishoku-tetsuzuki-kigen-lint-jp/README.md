# 退職手続き 期限リント — 健康保険 任意継続・国保・雇用保険

![退職手続き 期限リント — 健康保険 任意継続・国保・雇用保険](https://getreadystack.com/img/promo/sku249258_result_card.jpg)

退職者対応マニュアルや入退社手順書(Markdown)に書かれた**届出期限の誤記**を、行番号つきで指摘する VS Code 拡張です。生成AIに下書きさせた手順書は「任意継続は14日以内」「資格喪失届は10日以内」のように、もっともらしいけれど条文と違う日数を書きがちです。その1行が、退職者の任意継続の権利を失わせたり、会社の届出遅れ(健康保険法第208条:50万円以下の罰金)につながったりします。

無料のWeb版(同じエンジン): https://getreadystack.com/ja/tools/taishoku-tetsuzuki-kigen-lint-jp

**判定の基準(1行):** 健康保険法・雇用保険法施行規則・国民健康保険法・国民年金法・所得税法の各条文に書かれた期限と、手順書の日数を突き合わせます。

## 使い方

1. Markdown の手順書を開きます。
2. コマンドパレットから「…: Check this file」を実行します。有料版は「…: Sweep workspace and write report」、キーの入力は「…: Enter licence key」です。
3. 各指摘には、記載された日数・正しい期限・根拠条文が表示されます。

同梱のサンプル手順書では、7行の手続き案内のうち6行が指摘されます(資格喪失届10日→5日、雇用保険14日→10日、源泉徴収票「年末調整後」→1か月以内、算定基礎届の紙提出→特定の法人は電子申請、任意継続14日→20日、国保20日→14日)。

## 無料でできること / 有料版

- **無料:** 開いている手順書1ファイルを全12ルールで検査し、行番号と正しい期限を表示します。これだけで1冊の手順書の修正は完結します。
- **有料版(ライセンスキー):** ワークスペース内の手順書をまとめて検査し、根拠条文つきの監査レポートとして書き出します。社労士事務所や複数拠点の労務担当が、顧問先・拠点ごとの手順書をまとめて点検するときに使います。 → https://buy.polar.sh/polar_cl_KZSkyheopDkfDS34dTUwHHzbD9PIowoiuEpFR107gUw

## 検査しないこと

- 個別の事情(退職日が月末かどうか、扶養の有無など)による保険料の計算はしません。
- 協会けんぽ・健康保険組合ごとの独自の運用(申出書の到着日の扱いなど)は各保険者に確認してください。
- 本拡張は文書中の日数と条文の期限を突き合わせる検査ツールで、法的助言ではありません。

## よくある誤記の例

生成AIや古い社内文書で特に多いのは次の3つです。任意継続の申出を国民健康保険と同じ「14日以内」と書く誤り、国民健康保険の加入を任意継続と同じ「20日以内」と書く誤り、雇用保険の資格喪失届を社会保険と同じ「5日以内」と書く誤り(正しくは翌日から起算して10日以内)です。期限は数字が似ているため、取り違えがそのまま手順書に残ります。

## 動作環境

VS Code 1.80 以降。ネットワーク接続は、有料版のライセンスキーを確認するときだけ使います。検査は手元のエディタ内で完結し、手順書の内容は外部に送信しません。
