報酬・料金の源泉徴収を計算するコード（JavaScript / TypeScript / Python）を、国税庁タックスアンサー No.2795・No.2798 の式で検査する VS Code 拡張です。フリーランスへの支払、講演料、原稿料、弁護士・税理士報酬を払う請求・会計SaaSの開発者向け。

## 何を見つけるか（9規則）

| 規則 | 誤りの行 | 国税庁の式 |
|---|---|---|
| G01 | 源泉徴収率 `0.1` | `0.1021`（所得税10%×1.021） |
| G02 | 100万円超の部分 `0.2` | `0.2042` |
| G03 | `fee * 0.2042`（全額） | `(A - 1,000,000) × 0.2042 + 102,100` |
| G04 | `+ 100000` / `+ 102000` と 0.2042 | `+ 102100` |
| G05 | `Math.round` / `ceil` / `round()` | 1円未満の端数は切り捨て（`Math.floor`） |
| G06 | 復興 `0.011` を日付の分岐なしで使用 | 令和9年1月1日以後に生ずる所得だけ |
| G07 | 復興 `0.011` だけで防衛特別所得税なし | 所得税×(1 + 0.011 + 0.01) |
| G08 | 復興特別所得税の終了年 `2037`（令和19年） | 令和29年（2047年）分まで延長 |
| G09 | 税込額に源泉（情報） | 請求書で区分されていれば税抜の報酬額だけでよい（No.2792） |

## なぜ要るか

- 報酬¥1,500,000を0.2と+100000で計算すると源泉¥200,000、国税庁の式では¥204,200で¥4,200不足。
- 20.42%を支払額の全額にかけると、100万円超のどの金額でも¥102,100多く源泉される。
- 令和9年1月1日以後に生ずる所得から復興特別所得税は1.1%、防衛特別所得税1%が加わり、合計は10.21%のまま。チャットAIはこの1.1%を令和8年分に前倒ししがちで、防衛1%を付け忘れると合計10.11%になる。
- 源泉徴収した税は支払った月の翌月10日までに納付する。不足分を納めるのは支払者（源泉徴収義務者）です。

잣대 / 物差し: 誤りのコストはそのまま金額になる — 全額×20.42%なら1件 ¥102,100 の過大源泉、0.1のままなら報酬¥100,000ごとに¥210の不足。

## 使い方

1. `.js` `.ts` `.py` ファイルを開く。
2. コマンドパレットで「源泉徴収 計算チェック: このファイルを検査」。
3. 問題パネルに行番号・規則・正しい式が並ぶ。保存のたびに再検査。

規則は1行ずつ見ます。源泉徴収の文脈（`gensen` `源泉` `withhold` など）がない `0.1` は消費税とみなして触りません。`0.2042` の前後4行に `1000000` か `102100` があれば分割計算とみなします。
