# フリーランス新法 発注書チェック（明示事項・60日・30日前予告）

![フリーランス新法 発注書チェック](https://getreadystack.com/img/promo/sku111128_result_card.jpg)

業務委託の**発注書・業務委託契約書の Markdown** を開いた状態で 1 コマンド。
フリーランス新法（特定受託事業者に係る取引の適正化等に関する法律・2024-11-01 施行）が
書面／電磁的方法で明示するよう求める項目と、支払期日・予告期間を **21 個のルール**で照合し、
足りない行を行番号で返します。日付が書いてあれば、受領日から支払期日までの日数を**実際に計算**します。

## 何を見るのか

| 区分 | 見るもの |
| --- | --- |
| 第3条 明示事項 | 発注者名・受注者名・業務委託をした日・給付の内容・受領期日・**受領場所**・検査完了期日・報酬の額・支払期日・手形等の満期（10ルール） |
| 第4条 支払期日 | 受領日から支払期日までの日数が 60 日を超えていないか。「翌々月末払い」の支払サイト。再委託のときの元委託支払期日（3ルール） |
| 第16条 予告 | 6か月以上の継続的業務委託で、中途解除・不更新の予告が 30 日前までになっているか。契約終了日が迫っていないか（2ルール） |
| 第5条 禁止行為 | 報酬の減額・無償のやり直し・返品・購入の強制にあたる条項（4ルール） |
| 第13条/第14条 | 育児介護等への配慮の申出先、ハラスメント相談窓口の記載（2ルール） |

## 実測（同梱のサンプル `_fixtures/dirty.md`）

不備のある発注書 1 通を検査すると **12 件**（error 6 件 / warning 6 件）が出ます。そのうち計算で出る行はこれです。

```
FL-B11  受領日 2026-07-31 から支払期日 2026-10-30 まで 91日（31日 超過）
FL-B14  契約期間 12か月で予告が 14日前（16日 不足）
FL-B15  契約終了日 2026-10-05 まで残り 17日。30日前予告の期限は過ぎている
```

同梱の `_fixtures/clean.md`（整った発注書）は **0 件**です。

## 使い方

1. 発注書・契約書の `.md` を開く
2. コマンドパレット → `フリーランス新法: このファイルを検査`
3. 結果は「問題」パネルに行単位で出ます
