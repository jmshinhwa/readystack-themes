## 間違えたときに失うもの

- 国保の届出をしない・虚偽の届出: 市町村の条例で ¥100,000 以下の過料(国民健康保険法 第127条)
- 事業主が健康保険の資格取得・喪失の届出をしない: ¥500,000 以下の罰金(健康保険法 第208条)
- 任意継続は資格喪失日から20日を過ぎると、正当な理由がない限り申出できません(健康保険法 第37条)
