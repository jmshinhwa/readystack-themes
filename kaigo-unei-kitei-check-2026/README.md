# 介護 指定申請 運営規程チェック 2026

![介護 指定申請 運営規程チェック 2026](https://getreadystack.com/img/promo/sku219905_result_card.jpg)

**令和3年版の訪問介護 運営規程サンプルを 2026-09-23 付で検査すると、不備は6件でした。** 虐待防止の号なし・業務継続計画(BCP)なし・ウェブサイト掲載の記載なし・利用者負担「1割」のみ・廃止サービス名「介護予防訪問介護」・最新の施行日 2021-04-01。

介護保険の指定申請・指定更新で出す「運営規程」(.md / .txt)を VS Code で開くと、指定居宅サービス等基準(平成11年厚生省令第37号)の必須号と令和6年度改定の義務を **20 rules** で照合し、欠けた号を行番号と根拠条文つきで「問題」パネルに出します。

- 対象: 訪問介護・通所介護の事業所の管理者、開設準備中の法人、指定更新を控えた事業所
- 詳細: https://getreadystack.com/tools/kaigo-unei-kitei-check-2026
- 目安(人に頼む場合): 行政書士の指定申請代行には 132,000円(税込)の料金例があります(居宅介護・重度訪問介護の指定申請代行)。

## 何を検査するか(20 rules)

| 区分 | 規則 | 根拠 |
|---|---|---|
| 必須号(共通 8) | 目的及び運営の方針 / 従業者の職種・員数・職務の内容 / 営業日及び営業時間 / 内容及び利用料その他の費用の額 / 通常の事業の実施地域 / 緊急時等における対応方法 / 虐待の防止のための措置に関する事項 / その他運営に関する重要事項 | 第29条第1号〜第8号、第100条 |
| 通所介護の追加 3 | 利用定員 / サービス利用に当たっての留意事項 / 非常災害対策 | 第100条第4号・第7号・第9号 |
| 虐待防止 4措置 | 委員会 / 指針 / 研修 / 担当者 | 第37条の2第1号〜第4号 |
| 令和6年度改定 3 | 業務継続計画 / 重要事項のウェブサイト掲載 / 附則の最新施行日が 2024-04-01 より前 | 第30条の2、第32条第3項 |
| 古い記載 2 | 利用者負担を「1割」だけで記載 / 介護予防訪問介護・介護予防通所介護の名称 | 介護保険法、総合事業への移行 |

8 + 3 + 4 + 3 + 2 = 20 規則です。通所介護の3規則は、本文に「通所介護」または「デイサービス」があるときだけ動きます。

## 日付で答えが変わる

検査日(既定は今日)を基準に、経過措置が終わってから何日たったかをメッセージに添えます。

- 虐待防止措置: 経過措置は 2024-03-31 で終了。高齢者虐待防止措置未実施減算は所定単位数の100分の1。
- 業務継続計画: 減算の経過措置は 2025-03-31 で終了。業務継続計画未策定減算は所定単位数の100分の1(施設・居住系は100分の3)。
- ウェブサイト掲載: 令和6年厚生労働省令の附則第2条による経過措置は 2025-03-31 で終了。

同じ規程でも 2025-01-10 に検査すると「ウェブサイト掲載の経過措置終了(2025-03-31)まで残り 81 日」、2026-09-23 に検査すると「540 日経過」と表示されます。

## 使い方

1. 運営規程を Markdown かテキストで保存します(Word の場合は本文をコピーして .md に貼り付け)。
2. VS Code で開くと自動で検査し、「問題」パネルに行番号つきで表示します。
3. コマンドパレットから手動で再検査もできます。

全角数字(１割、令和６年)や改行で折り返された条文も、空白を詰めてから照合します。

## 無料でできること / 有料版

- 無料: 開いている運営規程1ファイルを20規則で検査し、欠けた必須号・未記載の義務・古い記載を行番号と根拠条文つきで一覧にします。これだけで1事業所の提出前チェックは終わります。
- 有料版(ライセンスキー): 複数事業所・複数サービス種別の運営規程をフォルダごと一括検査し、指定更新の提出前チェック表として不備一覧を書き出します。

## 検査しないこと

条文の中身が自治体の条例・要綱に合っているか(人員の常勤換算の妥当性、利用料の金額)は判断しません。都道府県・市町村の条例で独自の項目を足している場合があるため、提出先の様式も確認してください。本ツールは法律相談ではありません。
