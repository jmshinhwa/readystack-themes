# ReadyStack Warm Dark

A warm, low-glare dark theme for long sessions.

Most dark themes are cold and high-contrast. After a few hours that reads as glare.
This one sits on a paper-dark background with amber accents: **comments recede,
keywords lead, and numbers stay findable.**

## Install

1. Open the Extensions view
2. Search **ReadyStack Warm Dark**
3. Install, then `Ctrl+K Ctrl+T` and pick it

## What is tuned

- **Comments** are muted and italic - they should not compete with code
- **Strings** are green, **numbers** amber - two different kinds of literal, two different signals
- **Keywords** are gold and bold - the shape of the code is readable at a glance
- **Terminal** ANSI colors are matched to the editor, so output does not clash
- **Git decorations** follow the same palette - modified, added, deleted are distinct

Works with any language. Semantic highlighting on.
