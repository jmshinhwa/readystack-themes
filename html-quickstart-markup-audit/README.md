# HTML Quickstart & Markup Audit — 8 Packs

34 snippets and 30 rules across 8 HTML packs. The European Accessibility Act (EU Directive 2019/882) has applied to new products placed on the EU market since 28 June 2025, and a missing alt or a missing lang is the first thing the reviewer greps for before your invoice is signed off.

## What it does for free

- Every markup and accessibility problem in the page you have open, with line numbers
- The same 30 rules over only the block you highlighted
- All 34 snippets from the 8 packs, inserted at the cursor
- The full list of what is checked and what can be inserted

## With a licence

- **Check every page, component and template in the repository, not the one file** — Opens every file in the workspace and runs the same check on each.
- **Hand the client or the reviewer a findings file** — Writes the findings as a file (CSV, JSON or HTML) into the workspace folder; it uses the report_format setting when that is set, and only asks which format when it is not.
- **Swap the wrong head tag for the correct one in place** — Replaces the offending lines in the editor with the suggested text.

## Install

```
ext install html-quickstart-markup-audit
```
