# PCI 6.4.3 Payment Page Script Lint

![PCI DSS 6.4.3 Payment Page Script Lint](https://getreadystack.com/img/promo/sku21940_result_card.jpg)

Finds the third-party scripts, missing SRI hashes and CSP holes on your checkout page that fail PCI DSS 4.0.1 Requirements 6.4.3 and 11.6.1 - with the requirement number on every line.

## What it does for free

- Check the open payment page against every rule, with line number, severity and the PCI requirement number.
- Check only the lines you select.
- List every rule and its severity.
- Every finding is shown in full - nothing is blurred, counted down or held back.

## With a licence

- **Scan the whole repository, not only the open file** — Walks every file in the workspace, with the file limit and the exclude glob as settings, and reports all findings in one pass.
- **Export the findings as a CSV, JSON or HTML evidence file** — Writes the report into the workspace so it can be attached to an SAQ or handed to an assessor.
- **Re-check automatically on every save** — Turns the check into a background guard while the checkout page is being edited.
- **Write a machine-readable JSON report for CI** — Produces a JSON file in the workspace that a build step can read, so a regression on the payment page is caught before release.
