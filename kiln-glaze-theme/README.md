# Kiln — Pottery glaze colours: raku smoke, tenmoku iron, celadon jade.

![Kiln variants side by side](https://raw.githubusercontent.com/jmshinhwa/readystack-themes/main/kiln-glaze-theme/family.jpg)

**Three themes in one extension: Kiln Raku, Kiln Tenmoku, Kiln Celadon.**
Kiln takes its colours from glazed pottery rather than from neon: copper lustre for keywords, cobalt blue for strings, celadon green for numbers, ash-glaze straw for types and Jun-ware purple for parameters. Raku is the smoke-blackened clay just pulled from the fire, Tenmoku is the brown-black iron glaze of a tea bowl, and Celadon is the pale jade glaze for daylight. The grounds are matte and low in saturation like fired clay, so only the glaze colours stand out; body text is AAA and every syntax colour, comments included, is at least AA.

Every colour in your code is measured against its background. Body text passes WCAG AAA, and every syntax colour passes AA, **comments included**.

| Variant | Body text | Lowest syntax colour | Comments |
|---|---|---|---|
| Kiln Raku (dark) | 12.8:1 | 7.0:1 | 5.6:1 |
| Kiln Tenmoku (dark) | 13.5:1 | 6.6:1 | 5.5:1 |
| Kiln Celadon (light) | 12.6:1 | 5.2:1 | 4.9:1 |

## Install

1. Open the Extensions view (`Ctrl+Shift+X`, or `Cmd+Shift+X` on macOS) and search **Kiln**
2. Install, then `Ctrl+K Ctrl+T` (or `Cmd+K Cmd+T`) and pick Kiln Raku / Kiln Tenmoku / Kiln Celadon.
