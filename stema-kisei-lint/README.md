# ステマ規制チェック — アフィリエイト記事の広告表記リンター

![ステマ規制チェック — アフィリエイト記事の広告表記リンター](https://getreadystack.com/img/promo/sku130590_result_card.jpg)

AI に書かせた記事が、この規制を守っているか。2023-10-01 に景品表示法5条3号の指定告示（いわゆるステマ規制）が施行されてから、広告なのに広告だと分からない記事は、書き手ではなく**依頼した広告主**が措置命令の名宛人になります。この拡張は、公開前の記事を VS Code の中で12個のルールに当て、抜けている広告表記と不明瞭な表示を**行番号つき**で出します。

公式ハブ: https://getreadystack.com/ja/tools/stema-kisei-lint

## 何を見ているか（ルール12件 · ext/rules.json）

| ID | 何を見るか | 重さ |
| --- | --- | --- |
| AD-001 | アフィリエイトリンク（a8.net・もしも・楽天アフィリエイト・Amazon短縮・バリューコマース・アクセストレード等）があるのに、広告表記が記事のどこにもない | error |
| AD-002 | 広告表記はあるが、冒頭（既定で先頭8行）より後にしか出てこない | error |
| AD-003 | 「一部PRを含みます」「場合があります」のような、どの表示が広告か特定できない曖昧表記 | error |
| AD-004 | `display:none` `visibility:hidden` `opacity:0` `font-size:1px` など、表示を見えなくするスタイル | error |
| AD-005 | 商品提供・モニター・献本を本文に書いているのに、広告表記がない | error |
| AD-006 | 報酬・謝礼・対価・ギフト券の記述があるのに、広告表記がない | error |
| AD-007 | 広告のハッシュタグが5個以上のタグの列に埋もれている | warn |
| AD-008 | `Sponsored` `#ad` など英字だけの表記で、同じ行に日本語の表記がない | warn |
| AD-009 | 「タイアップ」「ご提供」だけで、広告表示だと伝わらない | warn |
| AD-010 | No.1・第1位・最安値の表示に、調査の出典・時点・範囲がない | warn |
| AD-011 | 「今だけ」「期間限定」に終了日がない | warn |
| AD-012 | 広告表記が画像（alt・バナー）だけに置かれている | warn |

## 使い方

1. 記事ファイル（`**/*.{md,mdx,html}`）を開く
2. コマンドパレットから `ステマ規制チェック: この記事を検査` を実行
3. 指摘が「行番号 · ルールID · 直し方」の形で出ます

## 判定の根拠と限界

- 根拠: 景品表示法5条3号、内閣府告示「一般消費者が事業者の表示であることを判別することが困難である表示」（2023-10-01 施行）、消費者庁の運用基準
- 措置命令に従わなかった場合の罰則は2年以下の拘禁刑または300万円以下の罰金、法人には3億円以下の罰金です
- 外注の目安: 弁護士の法律相談は30分5,500円（税込）
- 限界: これは法律助言ではありません。文字列の規則で判定するため、画像の中の文字や、JavaScript で後から差し込む表記は読めません。AD-001 は「広告」「PR」等の語が記事のどこかにあるかを見るため、本文で偶然その語に触れているだけの記事は無表記として検出されません
- 記事の本文は端末の外に出ません。ネットワークに出るのはライセンスキーの検証のときだけです
