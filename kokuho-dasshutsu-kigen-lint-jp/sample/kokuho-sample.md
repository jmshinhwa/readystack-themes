# 入退社チェックリスト(人事オペレーション)

## 入社時
- [ ] 健康保険・厚生年金の資格取得届を入社日から10日以内に年金事務所へ提出
- [ ] 雇用保険の資格取得届は入社日から5日以内にハローワークへ
- [ ] 被扶養者異動届は扶養に入る日から14日以内
- [ ] 本人へ: 前職の後に入っていた国保は、会社の保険に入れば自動で脱退されるので手続き不要
- [ ] 国保の脱退手続きは加入後1か月以内に市役所へ(20日以内が目安)
- [ ] 新しい保険証の発行を待ってから通院してもらう

## 退職時
- [ ] 健康保険の資格喪失届: 退職日の翌日から10営業日以内
- [ ] 雇用保険の資格喪失届・離職票: 退職日の翌日から14日以内
- [ ] 本人へ: 任意継続の申出は退職後1か月以内
