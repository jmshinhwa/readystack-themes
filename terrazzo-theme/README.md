# Terrazzo — Stone chips in polished cement: rosa, giallo, lapis, verde.

![Terrazzo variants side by side](https://raw.githubusercontent.com/jmshinhwa/readystack-themes/main/terrazzo-theme/family.jpg)

**Three themes in one extension: Terrazzo Nero, Terrazzo Rosso, Terrazzo Bianco.**
Terrazzo is the speckled floor of old Venetian palazzi and mid-century lobbies: chips of marble poured into cement and polished flat. Each syntax role is one kind of stone chip, so keywords are rosa marble, strings are giallo Siena, numbers are lapis blue, types are verde Alpi and functions are terracotta. The cement grounds stay matte and low in saturation, so only the chips catch your eye. Body text is AAA and every syntax colour, comments included, is at least AA.

Every colour in your code is measured against its background. Body text passes WCAG AAA, and every syntax colour passes AA, **comments included**.

| Variant | Body text | Lowest syntax colour | Comments |
|---|---|---|---|
| Terrazzo Nero (dark) | 13.5:1 | 7.5:1 | 5.6:1 |
| Terrazzo Rosso (dark) | 12.8:1 | 7.5:1 | 5.3:1 |
| Terrazzo Bianco (light) | 13.1:1 | 4.9:1 | 5.0:1 |

## Install

1. Open the Extensions view (`Ctrl+Shift+X`, or `Cmd+Shift+X` on macOS) and search **Terrazzo**
2. Install, then `Ctrl+K Ctrl+T` (or `Cmd+K Cmd+T`) and pick Terrazzo Nero / Terrazzo Rosso / Terrazzo Bianco.
